🍽️ Food Paradise

A modern, responsive, and visually appealing restaurant landing page showcasing a diverse menu of delicious foods, including Western dishes, Veg & Non-Veg options, and refreshing drinks.

✨ Features
Responsive Design: Optimized for all screen sizes, from desktops to mobile devices.

Modern Hero Section: Features a stunning background overlay, bold typography, and a prominent "Book a Table" call-to-action button.

Special Menu Grid: A responsive card-based layout featuring delicious item images, hover animations, descriptions, and pricing.

Clean Navigation: Flexbox-powered navigation bar with smooth hover state transitions.

🛠️ Built With
HTML5 – Semantic structure and layout elements.

CSS3 – Custom styling, modern layouts (Flexbox/Grid), smooth hover transitions, and responsive media queries.

🚀 Getting Started
To get a local copy up and running, follow these simple steps:

Clone or Download the Project:
Download the project files to your local machine.

Open the Directory:
Ensure both index.html and style.css are saved in the exact same folder.

Launch the Website:
Simply double-click the index.html file to open it instantly in your favorite web browser (Chrome, Safari, Edge, Firefox).
